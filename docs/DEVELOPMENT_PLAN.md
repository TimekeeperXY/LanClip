# LanClip 开发计划

## 产品目标

先交付可在 Windows 设备间运行的文字与截图自动同步工具，同时保证网络协议、数据模型和剪贴板接口不绑定 Windows，为 Windows ↔ macOS 与 macOS ↔ macOS 留出清晰升级路径。

## 第一阶段：Windows MVP

状态：开发中

- [x] Tauri 2 + React + TypeScript 工程骨架
- [x] 设备身份生成与本地配置
- [x] 局域网自动发现
- [x] 限时一次性配对码
- [x] 可信设备独立密钥与认证加密
- [x] 文字、图片剪贴板读写
- [x] 双向自动同步与防回环
- [x] 暂停同步、重命名、解除绑定
- [x] 托盘入口与中文桌面界面
- [x] 前端生产构建
- [x] 可信设备地址持久化，避免 UDP 单向发现造成单向同步
- [x] 入站连接地址学习与短暂失败重试
- [ ] 两台 Windows 真机互通测试
- [ ] Windows 安装包与防火墙引导

验收标准：两台 Windows 电脑在同一局域网首次配对后，任意一边复制文字或截图，另一边能在 2 秒内粘贴；重复内容不来回回传；暂停或解除绑定后立即停止接收。

## 第二阶段：安全与稳定性

- [ ] 使用 SPAKE2/OPAQUE 一类 PAKE 替换短码派生配对
- [x] Windows Credential Manager 安全保存设备密钥
- [x] 开机自启与后台托盘启动
- [x] 防火墙状态诊断和一键授权
- [x] NSIS 安装包自动添加/移除防火墙规则
- 端口冲突处理、网络变化恢复与退避重连
- 防火墙权限引导和诊断页
- 敏感内容暂停、应用黑名单与图片尺寸策略
- 自动化协议测试、异常帧测试和长时间稳定性测试
- 代码签名、自动更新与崩溃恢复

验收标准：断网、休眠、切换 Wi-Fi 后自动恢复；不可信设备与被篡改消息无法写入剪贴板；连续运行 24 小时无明显资源增长。

- [x] 验证 macOS 原生截图、浏览器/预览复制图片与 Windows 常见截图工具复制行为
- [x] 为 GitHub Actions 增加 macOS 编译与测试护栏
- [ ] 在 Intel Mac 上补充验证
- [x] 加入 macOS 菜单栏常驻、关闭窗口隐藏与登录启动基础支持
- [x] 真机验证 macOS 菜单栏重新打开、菜单栏退出与重启后后台自启
- [x] 为发布流程加入 macOS DMG 与 `.app` zip 构建任务
- [ ] 使用 Keychain 保存可信设备密钥
- [ ] 完成 macOS 权限说明、公证与签名
- [ ] Windows ↔ macOS、macOS ↔ macOS 交叉测试

验收标准：三种设备组合都能同步 Unicode 文字和常见截图，配对数据和协议保持兼容。

### Windows ↔ macOS 真机验证记录

- macOS 端应用可通过 `npm run tauri dev` 成功启动，主要功能页面可打开。
- Windows 与 macOS 可在同一局域网内互相发现、配对并保持在线状态。
- Windows → macOS 与 macOS → Windows 的纯文本同步均成功。
- Windows → macOS 与 macOS → Windows 的截图、图片同步均成功，传输记录缩略图正常显示。
- macOS 原生截图快捷键、`screencapture -c`、浏览器/预览复制图片，以及 Windows PixPin、Snipaste、微信、浏览器复制图片均已验证成功。
- macOS 端已验证菜单栏常驻逻辑：关闭窗口后继续同步，菜单栏可重新打开或退出；登录启动使用 LaunchAgent 并以后台模式启动。

## 第四阶段：增强功能

- 可选的加密剪贴板历史
- 手动发送与接收确认模式
- 多设备分组和仅发送/仅接收策略
- 文件传输与大图流式传输
- 二维码配对与设备指纹核验

## 当前明确边界

- MVP 仅同步纯文本和位图，不同步 HTML、富文本、文件及文件夹。
- 单张图片限制 20 MB，单条网络消息限制 32 MB。
- 传输记录只保留在进程内存中，重启后清空。
- 当前首次配对适合可信局域网，不承诺抵抗能够长期监听并主动攻击网络的对手。
